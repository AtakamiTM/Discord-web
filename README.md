This project aims to recreate the user interface of the Discord application. Using HTML, CSS, and JavaScript, a visual copy of the popular communication application was created, including the main UI elements such as:

Sidebar: Contains a list of servers, icons, and a navigation bar for browsing channels.

Text and Voice Channels: Allows you to create and navigate between channels, both text and voice.

User Lists: Panels for displaying active users and their statuses.
