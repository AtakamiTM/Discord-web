# Discord UI Recreation

This project aims to recreate the user interface of the popular communication application, Discord. Using HTML, CSS, and JavaScript, a visual copy of the main UI elements has been created to mimic the structure and layout of the app. The following components have been implemented:

## Features:

* **Sidebar:** Contains a list of servers, icons, and a navigation bar for browsing through channels.

* **Text and Voice Channels:** Allows you to create and navigate between different types of channels (text and voice).

* **User Lists:** Panels for displaying active users, their online statuses, and their profiles.

## Technologies Used:

* HTML
* CSS
* JavaScript
